# Real-device photos

This folder is ready for photos of Daybook running on the Kindle. No real-device photos are included yet. The images elsewhere in the documentation are rendered previews with sample data.

## Add photos later

1. On GitHub, open `docs/photos` and choose **Add file → Upload files**.
2. Upload JPG or PNG photos with simple names such as `kindle-dashboard.jpg`, `kindle-progress.jpg`, or `kindle-journal.jpg`.
3. Commit the upload, then edit the main `README.md` to add an image:

```markdown
![Daybook running on a Kindle Basic](docs/photos/kindle-dashboard.jpg)
```

Photograph sample tasks and journal entries. Keep bot tokens, pairing settings, private chats, and personal journal text out of the pictures. A dashboard photo, a progress photo, and an overview of the Kindle beside Telegram would show the project well.
